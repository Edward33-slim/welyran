# mykeyboard

لوحة مفاتيح Android خفيفة تعمل كـ IME.

- الاسم: mykeyboard
- minSdk: Android 7.0 (API 24)
- targetSdk: 34
- ABI: armeabi-v7a و arm64-v8a
- اللغة: Java
- لا تحتاج إلى صلاحية الإنترنت.
- الواجهة: حروف إنجليزية، Shift، حذف، مسافة، Enter، أرقام ورموز.

## البناء

استخدم Android Studio أو Gradle 8.7 مع JDK 17 وافتح مجلد mykeyboard.

## التفعيل

بعد التثبيت:
1. افتح التطبيق.
2. اضغط "فتح إعدادات لوحة المفاتيح".
3. فعّل mykeyboard.
4. اختر mykeyboard من قائمة طرق الإدخال.
