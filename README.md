# mykeyboard

لوحة مفاتيح Android خفيفة تعمل كـ IME.

- الاسم: **mykeyboard**
- Android 7.0 (API 24) وأحدث
- `armeabi-v7a` و `arm64-v8a` عبر حزمة Android الافتراضية
- إنجليزي / عربي
- Shift
- أرقام ورموز
- مسافة / حذف / Enter
- بدون اتصال بالإنترنت أو مكتبات خارجية

## البناء

المشروع يستخدم Android Gradle Plugin 8.5.2 وGradle 8.7 وJDK 17. هذه التركيبة متوافقة حسب توثيق Android الرسمي. citeturn0search0

## الاستخدام

ثبّت APK، ثم افتح التطبيق واضغط **إعدادات لوحات المفاتيح**، فعّل `mykeyboard`، وبعدها اختره من قائمة لوحات المفاتيح.
