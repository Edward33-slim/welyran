# Downloads10 — Native Kotlin Download Manager + WebView Browser

- Native Kotlin Android application.
- Android 7.0+ (API 24).
- Main download manager stays native.
- Browser is an in-app WebView.
- Download cards are always dark.
- HTTP/HTTPS downloads with Range resume where the server supports it.
- Pause/resume/cancel, persistent queue, 1–10 concurrency setting.
- Real byte counts and speed.
- Browser: URL/search bar, menu, tab management, bookmarks, desktop user-agent,
  dark web mode, font scaling, image blocking, basic local ad-block patterns,
  Arabic translation redirect, and WebView download interception.

Important:
- Web sites can restrict WebView, DRM, bots, authentication, or downloads.
- No browser can guarantee access to every site or block every advertisement.
- Google Translate availability depends on the target site and network.
